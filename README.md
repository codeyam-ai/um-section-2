# um-section-2

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/codeyam-ai/um-section-2?quickstart=1)

Hallway (working name): a place where recent and soon-to-be grads pick a career
field, find a professional working in it, and book a short chat for advice.
Professionals can offer free intros or charge for their time.

## Open it in Codespaces

Click the button above. The codespace installs the CodeYam Editor, the Claude
Code CLI and a browser for screenshots; the first start takes a few minutes.
When the terminal shows a boxed "CodeYam Editor is ready" with a link, Cmd+click
it (Ctrl+click on Windows or Linux) and sign in to Claude inside the editor.

## Where things are

- `.codeyam/design/project_mockups/`: six design directions for the landing
  page and first-time visitor flow (pick a field, then a person).
- `.codeyam/design/mockup_generators/`: the Python scripts that build those
  mockups (`python3 m1.py` rewrites `01-…`, and so on).
- `.codeyam/design/answers.json`: the answers that shaped the designs.
- `.devcontainer/`: the Codespaces setup, generated by
  `codeyam-editor editor devcontainer-setup`.

No design has been picked yet. Reopen the design chat and say "let's use N" to
lock one in.
